1.2 Jangan memakai setBrandTheme untuk E-PPAT

HE-UMUM-01

import { setCustomTheme } from '@idds/react';
import { eppatTheme } from './brand-eppat-idds/eppat-theme';
setCustomTheme(eppatTheme);

1.6 Batasi !important dan penimpaan gaya

HE-UMUM-01

Jangan menimpa gaya IDDS dengan !important secara luas. Tulis penyesuaian dengan cakupan [data-brand='eppat'] .ina-… dan pakai token var(--ina-…). eppat.css hanya memakai !important di tempat IDDS juga memakainya (misalnya teks placeholder Select).

/* Benar */
[data-brand='eppat'] .ina-breadcrumb__link--active { color: var(--ina-primary-600); }

/* Salah */
.text-gray-400 { color: #999 !important; }
