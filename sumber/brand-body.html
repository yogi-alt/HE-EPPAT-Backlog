Brand mode untuk IDDS

E-PPAT

E-PPAT memakai komponen, tipografi, spasi, dan warna status dari INA Digital Design System. Yang diganti hanya warna brand: hijau E-PPAT sebagai warna utama dan emas kartu kantor sebagai warna pendamping.

Palet warna

Warna diambil dari tema yang aktif di aplikasi E-PPAT, lalu disusun menjadi skala 25–900 seperti brand IDDS lainnya.

Primary — hijau E-PPAT

Dipakai untuk tombol utama, tab aktif, tautan, dan fokus. Teks putih di atas warna utama memiliki kontras 6,06:1 (lolos WCAG AA).

Secondary — emas kartu kantor

Dipakai untuk aksen pendukung, misalnya kartu identitas kantor di sidebar.

Warna khusus E-PPAT

Token tambahan untuk bagian yang hanya ada di E-PPAT, seperti sidebar dan kartu kantor.

Warna status — tetap milik IDDS

Warna status tidak diubah agar arti hijau, merah, kuning, dan biru sama di seluruh layanan pemerintah.

Cara memakai

Pilih sesuai teknologi aplikasi. Ketiganya memakai jalur resmi IDDS tanpa mengubah library.

/* 1. CSS IDDS lebih dulu, lalu brand E-PPAT */
import '@idds/react/index.css';          // atau <link href="…/@idds/styles/dist/index.min.css">
import './brand-eppat-idds/eppat.css';

/* 2. Aktifkan brand (mendukung mode terang & gelap) */
document.documentElement.setAttribute('data-brand', 'eppat');
import { setCustomTheme, setThemeMode } from '@idds/react';
import { eppatTheme } from './brand-eppat-idds/eppat-theme';

setCustomTheme(eppatTheme);   // API resmi IDDS untuk brand di luar daftar bawaan
setThemeMode('light');
/* Tailwind v4 */
@import 'tailwindcss';
@import '@idds/styles/tailwind/css/idds.css';
@import './brand-eppat-idds/tailwind/eppat.css';

/* Kelas yang tersedia: bg-primary-500, text-primary-primary,
   bg-eppat-sidebar-bg, bg-eppat-office-card, dll. */
